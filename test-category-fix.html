💡 Troubleshooting Tips

  • Extension not loading: Check chrome://extensions/ and reload TabOracle
  • No tabs found: Make sure you have multiple tabs open with different content
  • Category tab empty: Check console for error messages
  • Icons not showing: Verify icon files exist and are properly referenced
