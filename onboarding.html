Welcome to TabOracle

To enable AI features on your device, please turn on Chrome’s Prompt API (on-device model). This is a one-time setup and stays fully offline.

Step 1: Open Chrome flags for the Prompt API.
chrome://flags/#prompt-api-for-gemini-nano
Step 2: Enable these flags and relaunch Chrome:
  • Enable Prompt API for Gemini Nano
  • Enable Optimization Guide On Device Model (if present)
Step 3: Test the model.

Privacy: All processing is local. No data leaves your device.
