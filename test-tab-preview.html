🚀 How to Test

  1. Install TabOracle Extension: Load the extension in Chrome developer mode
  2. Open Popup: Click the TabOracle icon or press Ctrl+Space
  3. Navigate Tabs: Switch between Search, Categories, AI Search, and Summary tabs
  4. Hover for Previews: Hover over any tab to see the enhanced preview
  5. Test Scrolling: Scroll through long lists of tabs with smooth scrolling
