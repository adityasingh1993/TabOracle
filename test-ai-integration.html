🔧 Troubleshooting

If "Explain Me" doesn't appear:
  • Make sure TabOracle extension is installed and enabled
  • Check if contextMenus permission is granted
  • Try refreshing the page and selecting text again
  • Check the browser console for error messages
If AI explanations aren't working:
  • Ensure Chrome Language Model API is enabled (Chrome 114+)
  • Go to chrome://flags/#enable-language-model-api and set to "Enabled"
  • Restart Chrome completely after enabling the flag
  • Check if you're using a supported Chrome version
  • Verify the extension has necessary permissions
  • Look for AI-related errors in the console
