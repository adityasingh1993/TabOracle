🚀 How to Test the New Tabbed Interface

  • Reload the Extension: Go to chrome://extensions/ and click the refresh button on TabOracle
  • Open the Popup: Click the TabOracle icon in your toolbar
  • Try Each Tab: Click between Normal Search, Category Search, and Smart Search
  • Test Search Modes: Each tab has different search capabilities and UI
  • Category Browsing: In Category Search, click on category cards to see grouped tabs
  • Smart Search: In Smart Search, try semantic queries like "code" or "development"
