# TabOracle - Intelligent Tab Management

A powerful Chrome extension that revolutionizes how you manage and interact with your browser tabs using AI-powered features and intelligent organization.

## 🚀 Features

### 🔍 Smart Tab Search
- **Instant Search**: Press `Ctrl+Space` (or `Alt+Space` on Mac) to instantly search through all your open tabs
- **Fuzzy Matching**: Find tabs even with partial matches in titles or URLs
- **Real-time Results**: See search results as you type

### 📂 Intelligent Categorization
- **Auto-Categorization**: Tabs are automatically organized into logical categories
- **Smart Grouping**: Social media, productivity, entertainment, and more
- **Quick Navigation**: Jump between categories with ease

### 🤖 AI-Powered Features
- **Explain Me**: Right-click any page to get an AI-generated explanation of the content
- **Smart Summaries**: Generate concise summaries of web pages
- **Context-Aware**: AI understands the context of your browsing

### 🎯 Enhanced Productivity
- **Keyboard Shortcuts**: Full keyboard navigation support
- **Quick Actions**: Pin, close, or switch tabs instantly
- **Responsive Design**: Works seamlessly across different screen sizes

## 🛠️ Installation

### From Chrome Web Store
1. Visit the [Chrome Web Store](link-to-be-added)
2. Click "Add to Chrome"
3. Confirm the installation

### Manual Installation (Development)
1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension directory

## 🎮 Usage

### Quick Start
1. **Open TabOracle**: Click the TabOracle icon or press `Ctrl+Space`
2. **Search Tabs**: Type to search through your open tabs
3. **Browse Categories**: Click on categories to see related tabs
4. **Use AI Features**: Right-click any page and select "Explain Me"

### Keyboard Shortcuts
- `Ctrl+Space` (Windows/Linux) or `Alt+Space` (Mac): Open TabOracle
- `Escape`: Close TabOracle
- `Arrow Keys`: Navigate through results
- `Enter`: Select highlighted item

### AI Features
- **Explain Me**: Right-click → "Explain Me" to get AI explanation
- **Pin Panel**: Click the pin button to dock the explanation panel
- **Generate Summary**: Use the summary feature in the popup

## 🔧 Technical Details

### Architecture
- **Manifest V3**: Built with the latest Chrome extension standards
- **Service Worker**: Background processing for optimal performance
- **Content Scripts**: Seamless integration with web pages
- **AI Integration**: On-device AI with intelligent fallbacks

### Permissions
- `tabs`: Access to tab information for search and organization
- `storage`: Save user preferences and settings
- `scripting`: Inject content scripts for AI features
- `offscreen`: Handle PDF processing
- `contextMenus`: Right-click menu integration

### Privacy
- **No Data Collection**: TabOracle doesn't collect or store your browsing data
- **Local Processing**: AI features work locally when possible
- **Minimal Permissions**: Only requests necessary permissions
