🚀 How to Test in TabOracle Extension

  1. Install the Extension: Load TabOracle in Chrome developer mode
  2. Open Popup: Click the TabOracle icon or press Ctrl+Space
  3. Test Each Tab: Switch between Search, Categories, AI Search, and Summary tabs
  4. Verify Scrolling: Each tab should scroll independently without affecting the popup body
  5. Check Content: All content should be accessible through tab scrolling
