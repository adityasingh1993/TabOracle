# TabOracle Privacy Policy

**Last updated: August 2024**

## Overview

TabOracle is a privacy-first Chrome extension that provides intelligent tab management and search capabilities. This privacy policy explains how we handle your data and what information the extension accesses.

## Data Collection

**We do not collect, store, or transmit any of your personal data or browsing information.**

### What TabOracle Accesses

TabOracle requires the following permissions to function:

- **Tab Information**: Access to titles, URLs, and basic metadata of your open tabs
- **Page Content**: Temporary access to page content for search and analysis
- **Storage**: Local storage for extension settings only
- **PDF Processing**: Access to PDF files for text extraction and search

### What We Don't Access

- Personal information
- Browsing history
- Passwords or login credentials
- Form data
- Private browsing sessions
- Other extensions' data

## How Data is Processed

### Local Processing Only

All data processing happens entirely on your device:

- **Search Analysis**: Tab content is analyzed locally for search relevance
- **AI Features**: Uses Chrome's on-device Language Model (Gemini Nano)
- **PDF Processing**: PDF text extraction happens locally using pdf.js
- **Categorization**: Tab categorization uses local algorithms

### No Cloud Services

- No data is sent to external servers
- No analytics or tracking
- No user profiling
- No data sharing with third parties

## PDF Handling

When you use TabOracle with PDF files:

1. **Local Download**: PDFs are downloaded to your device temporarily
2. **Text Extraction**: Text is extracted using pdf.js library
3. **Local Storage**: Extracted text is stored locally for search
4. **No Upload**: PDF content is never uploaded or transmitted



## Storage

### Local Storage Only

TabOracle stores minimal data locally:

- Extension settings (e.g., PDF debugger toggle)
- Cached tab content for search
- No personal or browsing data

### Data Retention

- Cached content is cleared when tabs are closed
- Settings persist until you uninstall the extension
- No data is retained after uninstallation

## Third-Party Services

### Chrome APIs

TabOracle uses Chrome's built-in APIs:
- `chrome.tabs`: For tab management
- `chrome.storage`: For local settings
- `chrome.scripting`: For content extraction
- `chrome.languageModel`: For AI features (optional)

### External Libraries

- **pdf.js**: For PDF text extraction (runs locally)
- No external analytics or tracking libraries

## Your Rights

You have complete control over your data:

- **Access**: All data is stored locally on your device
- **Deletion**: Uninstall the extension to remove all data
- **Control**: Disable permissions in Chrome settings
- **Transparency**: Review the source code for complete transparency

## Children's Privacy

TabOracle does not knowingly collect data from children under 13. The extension is designed for general audiences and does not require age verification.
